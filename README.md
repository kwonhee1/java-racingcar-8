# java-racingcar-precourse

# domain 분리
- 자동차
    - 이름을 입력 받는다
        - 5글자 이하만 가능하다
    - 1회 전진한다 
        - 0 ~ 9 사이에 무작위 값을 구한 후 4이상인 경우 전진한다
    - 현재 위치를 저장한다

# 기능 요구 사항
- [X] 자동차 이름들을 입력 받고 자동차들을 생성한다
- [X] 입력 받은 횟수를 입력 받는다 자동차 경주를 진행한다
- [X] 실행 결과를 출력한다
