# java-racingcar-precourse

# domain 분리
- 자동차
    - 이름을 입력 받는다
        - 5글자 이하만 가능하다
    - 1회 전진한다 
        - 0 ~ 9 사이에 무작위 값을 구한 후 4이상인 경우 전진한다
    - 현재 위치를 저장한다

# 기능 요구 사항
- 자동차 이름들과 시도할 횟수를 입력 받는다
- 입력 받은 횟수 만큼 자동차 경주를 진행한다
- 실행 결과를 출력한다
